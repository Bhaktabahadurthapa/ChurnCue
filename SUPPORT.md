# Support

## Usage questions

Review the [README](README.md), [Archestra setup](docs/ARCHESTRA_SETUP.md), and [architecture guide](docs/ARCHITECTURE.md) first. If the question remains, open a GitHub Discussion or a clearly scoped issue.

## Bug reports

Use the bug-report issue form and include reproducible steps, sanitized logs, Python/Docker versions, deployment mode, and the smallest anonymous input that demonstrates the problem.

## Security issues

Follow [SECURITY.md](SECURITY.md). Never disclose a vulnerability, credential, customer record, or exploit in a public issue.

## Support boundary

ChurnCue is an open-source hackathon project distributed without warranty. Community support is best effort. Production deployments should have their own operational ownership, monitoring, backups, and incident-response process.
